# APA 7 Reference by Icarus

Complete APA 7th edition citation and formatting rules.

## When to Use

- User asks about APA citation rules
- User needs to format in-text citations
- User needs to format reference list entries
- User asks about hanging indent, double-spacing, or other APA formatting
- User is writing academic papers and needs citation help

## Content

### 1. In-Text Citations

#### Basic Structure

| Authors | Parenthetical | Narrative |
|---------|-------------|-----------|
| 1 author | (Walker, 2007) | Walker (2007) |
| 2 authors | (Walker & Allen, 2004) | Walker and Allen (2004) |
| 3+ authors | (Bradley et al., 2006) | Bradley et al. (2006) |
| Organization | (American Psychological Association [APA], 2020) | American Psychological Association (APA, 2020) |

#### Special Cases

| Case | Format |
|------|--------|
| Same author, same year | (Pandey, 2020a, 2020b) |
| Same author, multiple years | (Koch, 1953–1956) or (Koch, 1953, 1956) |
| Direct quote | Must include page: (Parker, 2020, p. 67) or (Johnson, 2017, pp. 39–41) |
| Secondary source | (Parker, 1978, as cited in Bloom et al., 2017) |
| Multiple citations | Alphabetical, semicolon: (Adamson, 1989; Zelinsky, 2001) |
| Same author multiple works | (Department of Veterans Affairs, n.d., 2017a, 2017b, 2019) |
| No date | (n.d.) |
| Personal communication | Not in reference list; in-text only: (J. Smith, personal communication, January 15, 2020) |
| No author | Use title, abbreviated if long |
| Anonymous | Cite as "Anonymous" and alphabetize under "Anonymous" |

### 2. Reference List Formatting

#### Page Setup

| Element | Rule |
|---------|------|
| Title | "References" centered, bold, new page |
| Spacing | Double-spaced throughout |
| Indent | Hanging indent 0.5 inch (1.27 cm) |
| Order | Alphabetical by first author surname |
| Author names | Inverted: Smith, J. M. |

#### Author Rules

- 1–19 authors: List all
- 20 authors: List all
- 21+ authors: First 19 + ellipsis + last author
- Suffixes: King, M. L., Jr. or King, M. L., III
- Hyphenated: Smith-Jones, J.

#### Title Capitalization

- Article titles: Sentence case (first word capitalized, rest lowercase except proper nouns)
- Journal/book titles: Title case (major words capitalized)

### 3. Reference Entry Formats

#### Journal Article
```
Author, A. A. (Year). Title of article: Subtitle. *Title of Journal, volume*(issue), pages. DOI/URL
```

Example:
```
Haybron, D. M. (2008). Philosophy and the science of subjective well-being. In M. Eid & R. J. Larsen (Eds.), *The science of subjective well-being* (pp. 17–43). Guilford Press.
```

#### Newspaper Article
```
Carey, B. (2019, September 9). Can we get better at forgetting? *The New York Times*. https://www.nytimes.com/2019/09/09/health/memory-forgetting-psychology.html
```

#### Web Page
```
American Psychological Association. (2020, October 21). Publications. https://www.apa.org/pubs
```

#### Book
```
Brown, B. (2015). *Daring greatly: How the courage to be vulnerable transforms the way we live, love, parent, and lead*. Avery.
```

#### Book Chapter
```
Author, A. A. (Year). Title of chapter. In B. B. Editor (Ed.), *Title of book* (pp. xxx–xxx). Publisher.
```

#### Dissertation/Thesis
```
Author, A. A. (Year). *Title of dissertation* (Doctoral dissertation). University Name. Database/URL
```

#### Preprint
```
Author, A. A. (Year). *Title of preprint* [Preprint]. Platform. URL
```

#### Personal Communication
Not in reference list; cite in-text only.

### 4. APA 6 vs APA 7 Changes

| Change | APA 6 | APA 7 |
|--------|-------|-------|
| Et al. threshold | 6+ authors | 3+ authors |
| Author list limit | 6 authors | 20 authors |
| DOI format | doi:10.xxxx/xxxxx | https://doi.org/xxxxx |
| URL | Optional | Required |
| Web page title | Quotation marks | Italicized |
| Book edition | Include place of publication | Omit place |
| Author suffixes | Not supported | Jr., III, etc. |

### 5. Common Errors

| Error | Correction |
|-------|------------|
| & vs and in parentheses | Use & in parentheses, and in narrative |
| et al. punctuation | et al., (with period and comma) |
| Bullet or numbered references | Use plain list, no bullets |
| Blank lines between entries | No blank lines, double-space only |
| Author name not inverted | First author inverted, subsequent authors normal |
| Year outside parentheses | Year must be inside parentheses |
| Article title in title case | Use sentence case for article titles |

### 6. Hanging Indent Setup

**Microsoft Word:**
1. Select all entries
2. Right-click → Paragraph
3. Indentation → Special → Hanging
4. By: 0.5"

**Google Docs:**
1. Select all entries
2. Format → Align & indent → Indentation options
3. Special indent → Hanging
4. 0.5"

**LaTeX:**
```latex
\usepackage{hanging}
\begin{hangparas}{0.5in}{1}
% reference entries here
\end{hangparas}
```
